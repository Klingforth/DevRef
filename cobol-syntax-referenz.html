▓ COBOL Syntax
GnuCOBOL · Free-Format · Arch Linux / CachyOS
COBOL – Common Business-Oriented Language (1959, Grace Hopper). Läuft auf ~95% aller Geldautomaten und verarbeitet täglich $3 Billionen Transaktionen. Weltweit gibt es schätzungsweise 220 Milliarden Zeilen aktiven COBOL-Codes.
Diese Referenz verwendet Free-Format (GnuCOBOL mit cobc -free) – keine festen Spaltenregeln, normale Einrückung.
Fixed-Format Spaltenstruktur (classic COBOL) 
│123456│7│8 9 A B│C – Spalte 72  (Area B: eigentlicher Code)│73–80│
│Zeilen│*│Area A  │Area B                               │Ident│
│nummer│=│DIV.    │Statements, Datendefinitionen, ...   │      │
│      │Kom│SECTION │                                     │      │
│      │men│01/77   │                                     │      │
│      │tar│Pgr-Name│                                     │      │
■ Zeilennummer (opt.)   ■ Indikator (* = Kommentar)   ■ Area A (DIVISION, 01, 77)   ■ Area B (Code)   ■ Identifikation (ignoriert)

Level-Nummern & Datenstrukturen 
       *> Level 01: Gruppenfelder (Datensätze)
       01 KUNDEN-SATZ.
           05 KD-NUMMER      PIC 9(6).
           05 KD-NAME.
               10 KD-VORNAME PIC X(15).
               10 KD-NACHNAME PIC X(15).
           05 KD-ADRESSE.
               10 KD-STRASSE PIC X(30).
               10 KD-PLZ     PIC 9(5).
               10 KD-ORT     PIC X(20).
           05 KD-KONTO       PIC S9(10)V99.

       *> Level 77: Einzelne unabhängige Felder (veraltet → 01 bevorzugen)
       77 WS-ZAEHLER         PIC 9(4).

       *> Level 66: RENAMES – Alias für Felder
       66 KD-VOLLNAME        RENAMES KD-VORNAME THRU KD-NACHNAME.

       *> Level 88: Condition-Names (boolesche Bedingungen!)
       01 WS-STATUS          PIC X.
           88 STATUS-OK      VALUE "Y".
           88 STATUS-FEHLER  VALUE "N" "E".
           88 STATUS-LEER    VALUE SPACE.

       *> Verwendung von Level-88:
           IF STATUS-OK
               DISPLAY "Alles in Ordnung"
           END-IF
           SET STATUS-OK TO TRUE  *> WS-STATUS = "Y"

MOVE – Daten zuweisen 
       *> Einfaches MOVE
       MOVE "Hallo"          TO WS-TEXT
       MOVE 42               TO WS-ZAHL
       MOVE SPACES           TO WS-TEXT

       *> MOVE mit Typumwandlung (automatisch)
       MOVE WS-ZAHL-NUM      TO WS-ZAHL-STR  *> 42 → "42"
       MOVE WS-DATUM-NUM     TO WS-DATUM-ANZ *> 20240115 → "20240115"

       *> MOVE CORRESPONDING (CORR) – gleiche Feldnamen kopieren
       MOVE CORRESPONDING QUELLE-SATZ TO ZIEL-SATZ

       *> Mehrfach-MOVE
       MOVE "N"              TO WS-FLAG-A WS-FLAG-B WS-FLAG-C

       *> MOVE mit Level-88 setzen
       SET STATUS-OK         TO TRUE       *> setzt WS-STATUS = "Y"
       SET STATUS-FEHLER     TO TRUE       *> setzt WS-STATUS = "N"
Arithmetik 
       *> ADD
       ADD 1                 TO WS-ZAEHLER
       ADD WS-A WS-B         TO WS-SUMME
       ADD WS-A TO WS-B GIVING WS-SUMME  *> WS-B bleibt unverändert

       *> SUBTRACT
       SUBTRACT 1            FROM WS-ZAEHLER
       SUBTRACT WS-KOSTEN    FROM WS-BUDGET GIVING WS-REST

       *> MULTIPLY
       MULTIPLY 2            BY WS-BETRAG
       MULTIPLY WS-PREIS     BY WS-MENGE GIVING WS-GESAMT

       *> DIVIDE
       DIVIDE 2              INTO WS-HÄLFTE
       DIVIDE WS-GESAMT BY WS-MENGE GIVING WS-STÜCKPREIS
           REMAINDER WS-REST

       *> COMPUTE – mathematische Ausdrücke wie in anderen Sprachen
       COMPUTE WS-ERGEBNIS   = (WS-A + WS-B) * WS-C / 100
       COMPUTE WS-MWS        = WS-NETTO * 0.19 ROUNDED
       COMPUTE WS-HYPOTENUSE = FUNCTION SQRT(WS-A ** 2 + WS-B ** 2)

       *> ON SIZE ERROR – Overflow abfangen
       COMPUTE WS-ERGEBNIS   = WS-A * WS-B
           ON SIZE ERROR
               DISPLAY "Überlauf!"
       END-COMPUTE
IF / EVALUATE – Bedingungen 
       *> IF ... ELSE ... END-IF
       IF WS-ALTER >= 18
           DISPLAY "Volljährig"
       ELSE
           DISPLAY "Minderjährig"
       END-IF

       *> Mehrere Bedingungen
       IF WS-PLZ >= 10000 AND WS-PLZ <= 19999
           DISPLAY "Berlin"
       ELSE IF WS-PLZ >= 20000 AND WS-PLZ <= 29999
           DISPLAY "Hamburg"
       ELSE
           DISPLAY "Andere Stadt"
       END-IF

       *> Level-88 Condition-Names
       IF STATUS-OK
           PERFORM VERARBEITE-SATZ
       END-IF

       *> EVALUATE – wie switch/case, aber viel mächtiger
       EVALUATE WS-AKTION
           WHEN "A"      PERFORM HINZUFÜGEN
           WHEN "U"      PERFORM AKTUALISIEREN
           WHEN "D"      PERFORM LÖSCHEN
           WHEN OTHER    DISPLAY "Ungültige Aktion: " WS-AKTION
       END-EVALUATE

       *> EVALUATE TRUE – mehrere Bedingungen testen
       EVALUATE TRUE
           WHEN WS-BETRAG < 0
               DISPLAY "Negativ"
           WHEN WS-BETRAG = 0
               DISPLAY "Null"
           WHEN WS-BETRAG <= 1000
               DISPLAY "Klein"
           WHEN OTHER
               DISPLAY "Groß"
       END-EVALUATE

       *> EVALUATE mit ALSO (mehrere Variablen gleichzeitig)
       EVALUATE WS-TYP ALSO WS-STATUS
           WHEN "A" ALSO "Y"   PERFORM AKTIV-A
           WHEN "B" ALSO "Y"   PERFORM AKTIV-B
           WHEN ANY  ALSO "N"  PERFORM INAKTIV
       END-EVALUATE
PERFORM – Schleifen & Unterprogramme 
       *> PERFORM: Paragraph aufrufen
       PERFORM INITIALISIERUNG
       PERFORM VERARBEITE-SATZ
       PERFORM ABSCHLUSS

       *> PERFORM THRU: Mehrere Paragraphen
       PERFORM INIT-START THRU INIT-ENDE

       *> PERFORM N TIMES
       PERFORM 10 TIMES
           DISPLAY "Iteration"
       END-PERFORM

       *> PERFORM UNTIL (Schleife)
       PERFORM UNTIL WS-EOF-FLAG = "Y"
           READ KUNDEN-DATEI
               AT END MOVE "Y" TO WS-EOF-FLAG
           END-READ
           PERFORM VERARBEITE-KUNDE
       END-PERFORM

       *> PERFORM VARYING (for-Schleife)
       PERFORM VARYING WS-INDEX FROM 1 BY 1
               UNTIL WS-INDEX > 12
           DISPLAY "Monat " WS-INDEX ": " MONAT-NAME(WS-INDEX)
       END-PERFORM

       *> PERFORM VARYING mit mehreren Variablen (verschachtelt)
       PERFORM VARYING ZEILE FROM 1 BY 1 UNTIL ZEILE > 10
           AFTER SPALTE FROM 1 BY 1 UNTIL SPALTE > 10
               COMPUTE MATRIX(ZEILE, SPALTE) = ZEILE * SPALTE
           END-PERFORM
       END-PERFORM

       *> Inline PERFORM (ohne Paragraph-Name)
       PERFORM WITH TEST AFTER
           UNTIL WS-EINGABE = "ENDE"
           DISPLAY "Eingabe: "
           ACCEPT WS-EINGABE
       END-PERFORM
CALL – Module aufrufen 
       *> Einfacher CALL
       CALL "RECHENMODUL"

       *> CALL mit Parametern (BY REFERENCE = Standard)
       CALL "BERECHNE-MWS"
           USING BY REFERENCE WS-NETTO
                 BY REFERENCE WS-MWS-BETRAG
                 BY CONTENT   WS-STEUERSATZ  *> nur lesen, nicht ändern
                 BY VALUE     42              *> Literal

       *> CALL mit Rückgabewert (COBOL 2002+)
       CALL "BERECHNE"
           USING WS-EINGABE
           RETURNING WS-ERGEBNIS

       *> Fehlerbehandlung beim CALL
       CALL "EXTERNES-MODUL"
           USING WS-DATEN
           ON EXCEPTION
               DISPLAY "Modul nicht gefunden!"
       END-CALL

       *> Dynamischer CALL (Modulname in Variable)
       MOVE "MODUL-V2"       TO WS-MODUL-NAME
       CALL WS-MODUL-NAME
           USING WS-DATEN

       *> GOBACK (aus aufgerufenem Modul zurückkehren)
       *> vs STOP RUN (beendet das gesamte Programm!)
       GOBACK.
STRING / UNSTRING – Textverarbeitung 
       *> STRING: Felder zusammensetzen
       STRING WS-VORNAME    DELIMITED BY SPACE
              " "           DELIMITED BY SIZE
              WS-NACHNAME   DELIMITED BY SPACE
           INTO WS-VOLLNAME
           WITH POINTER WS-POS
           ON OVERFLOW DISPLAY "Zu lang!"
       END-STRING

       *> UNSTRING: Feld aufteilen
       UNSTRING WS-CSV-ZEILE
           DELIMITED BY ";" OR ","
           INTO WS-FELD-1
                WS-FELD-2
                WS-FELD-3
           TALLYING IN WS-ANZAHL-FELDER
           ON OVERFLOW DISPLAY "Zu viele Felder!"
       END-UNSTRING

       *> INSPECT: Zeichen zählen und ersetzen
       INSPECT WS-TEXT
           TALLYING WS-ZAEHLER
               FOR ALL "A"
       INSPECT WS-TEXT
           REPLACING ALL ";" BY ","
       INSPECT WS-TEXT
           CONVERTING "abcdefghijklmnopqrstuvwxyz"
                    TO "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

       *> Intrinsische Funktionen (COBOL 2002+)
       MOVE FUNCTION UPPER-CASE(WS-TEXT)  TO WS-GROSS
       MOVE FUNCTION LOWER-CASE(WS-TEXT)  TO WS-KLEIN
       MOVE FUNCTION LENGTH(WS-TEXT)      TO WS-LAENGE
       MOVE FUNCTION TRIM(WS-TEXT)        TO WS-GETRIMMT
       MOVE FUNCTION CURRENT-DATE         TO WS-AKTUELL-DATUM
       MOVE FUNCTION NUMVAL("3.14")       TO WS-ZAHL

           01 WS-STATUS            PIC XX.
           01 WS-EOF               PIC X VALUE "N".

       *> ── Verarbeitungsschleife ─────────────────────────────
       PROCEDURE DIVISION.
           OPEN INPUT EINGABE-DATEI

           PERFORM UNTIL DATEI-ENDE
               READ EINGABE-DATEI
                   AT END
                       SET DATEI-ENDE TO TRUE
                   NOT AT END
                       PERFORM VERARBEITE-SATZ
               END-READ
           END-PERFORM

           CLOSE EINGABE-DATEI
           STOP RUN.

       VERARBEITE-SATZ.
           DISPLAY EINGABE-SATZ.

       *> ── Ausgabedatei schreiben ────────────────────────────
           OPEN OUTPUT AUSGABE-DATEI
           WRITE AUSGABE-SATZ FROM WS-DATEN

INDEXED (ISAM) Dateien 
       *> ── Indexed Datei (wie eine Datenbanktabelle) ─────────
       FILE-CONTROL.
           SELECT KUNDEN-DATEI
               ASSIGN TO "kunden.idx"
               ORGANIZATION IS INDEXED
               ACCESS MODE IS DYNAMIC
               RECORD KEY IS KD-NUMMER
               ALTERNATE RECORD KEY IS KD-NAME
                   WITH DUPLICATES
               FILE STATUS IS WS-STATUS.

       *> ── Direktzugriff ────────────────────────────────────
           OPEN I-O KUNDEN-DATEI

           *> Lesen nach Schlüssel
           MOVE 123456         TO KD-NUMMER
           READ KUNDEN-DATEI
               KEY IS KD-NUMMER
               INVALID KEY
                   DISPLAY "Kunde nicht gefunden"
               NOT INVALID KEY
                   DISPLAY "Gefunden: " KD-NAME
           END-READ

           *> Schreiben (neuer Satz)
           MOVE 123457         TO KD-NUMMER
           MOVE "Schmidt"      TO KD-NAME
           WRITE KUNDEN-SATZ
               INVALID KEY DISPLAY "Schlüssel existiert bereits"
           END-WRITE

           *> Aktualisieren
           REWRITE KUNDEN-SATZ
               INVALID KEY DISPLAY "Satz nicht gefunden"
           END-REWRITE

           *> Löschen
           DELETE KUNDEN-DATEI RECORD
               INVALID KEY DISPLAY "Satz nicht gefunden"
           END-DELETE

           *> Sequentiell lesen ab Position
           MOVE "M"            TO KD-NAME
           START KUNDEN-DATEI
               KEY >= KD-NAME
               INVALID KEY DISPLAY "Kein Satz ab M"
           END-START
           PERFORM UNTIL WS-STATUS NOT = "00"
               READ KUNDEN-DATEI NEXT RECORD
                   AT END EXIT PERFORM
               END-READ
               DISPLAY KD-NAME
           END-PERFORM

           CLOSE KUNDEN-DATEI.
