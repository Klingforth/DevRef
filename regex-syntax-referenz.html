Regex – Muster für Text. Kleene 1951, Thompson 1968. PCRE ist der Standard.
. = beliebig  ·  * + ? {n} = Quantifizierer  ·  [abc] \d \w \s = Klassen  ·  ^ $ = Anker  ·  () = Gruppen  ·  Testen: regex101.com

Capture Groups & Referenzen 
# CAPTURE GROUPS  (...)
# Speichern den gematchten Text für Weiterverwendung

(\d{4})-(\d{2})-(\d{2})
# Matched: 2024-01-15
# Gruppe 1: 2024  Gruppe 2: 01  Gruppe 3: 15
#     =  Rückwärtsreferenz in Pattern selbst
# $1 $2 $3  =  In Ersetzungsstring

# NAMED GROUPS  (?P<name>...)  oder  (?<name>...)
(?P<jahr>\d{4})-(?P<monat>\d{2})-(?P<tag>\d{2})
# Python: match.group('jahr')
# JS:     match.groups.jahr
# .NET:   match.Groups["jahr"].Value

# NON-CAPTURING GROUP  (?:...)
# Gruppiert ohne Nummer zu vergeben (effizienter!)
(?:https?|ftp)://[\w./]+
# Matched URLs, aber Schema-Gruppe wird nicht gespeichert

# ATOMIC GROUP  (?>...)   [PCRE, nicht überall]
# Kein Backtracking innerhalb der Gruppe

# ALTERNATION IN GRUPPE
(cat|dog|bird)s?
# Matched: cat, cats, dog, dogs, bird, birds

# VERSCHACHTELT
((a|b)(c|d))
# Gruppe 1: ac, ad, bc, bd
# Gruppe 2: a oder b
# Gruppe 3: c oder d

# RÜCKWÄRTSREFERENZ IM PATTERN
# Matched wiederholte Wörter:
(\w+)\s+
# Input:  "das das ist toll toll"
# Treffer: "das das", "toll toll"

# HTML-Tag schließt sich selbst:
<(\w+)>.*?</>
# <div>Inhalt</div>  →  <div>...  </div>  mit ="div"
Lookahead & Lookbehind 
# LOOKAHEAD und LOOKBEHIND:
# Prüfen Kontext OHNE den Text zu konsumieren!
# Der gematchte Text enthält das Look-Teil NICHT.

# POSITIVER LOOKAHEAD  (?=...)
# "Was vor dem Match stehen muss"
\d+(?= Euro)
# Input:  "100 Euro und 200 Dollar"
# Treffer: "100" (nicht "200" weil kein Euro dahinter)

# NEGATIVER LOOKAHEAD  (?!...)
# "Was NICHT vor dem Match stehen darf"
\d+(?! Euro)
# Input:  "100 Euro und 200 Dollar"
# Treffer: "200" (kein Euro dahinter)

# POSITIVER LOOKBEHIND  (?<=...)
# "Was hinter dem Match stehen muss" (davor im Text)
(?<=\$)\d+
# Input:  "$100 and €200"
# Treffer: "100" (nach $, nicht nach €)

# NEGATIVER LOOKBEHIND  (?<!...)
(?<!\$)\d+
# Input:  "$100 and 200"
# Treffer: "200" (nicht nach $)

# KOMBINATION für genaue Matches
# Passwort: 8+ Zeichen, min. 1 Ziffer, 1 Großbuchstabe
^(?=.*\d)(?=.*[A-Z]).{8,}$
# Testet drei Bedingungen ohne Position zu verändern

# Email-Domain ohne @
(?<=@)[\w.]+
# Input:  "user@example.com"
# Treffer: "example.com"

# Preis ohne Währungszeichen
(?<=[$€£])\d+(?:\.\d{2})?
# Input:  "$9.99, €14.50, £7"
# Treffer: "9.99", "14.50", "7"

# VARIABLE LÄNGE LOOKBEHIND (PCRE2, .NET, Python 3.x)
# Python: (?<=\d{1,3})
# JS: NICHT unterstützt!  (feste Länge nötig)
# .NET: beliebige Länge erlaubt

Greedy vs. Lazy vs. Possessiv:
* greedy – nimmt so viel wie möglich  ·  *? lazy – nimmt so wenig wie möglich  ·  *+ possessiv – nimmt alles, gibt nichts zurück (PCRE)
Pattern Bedeutung Beispiel-Input Treffer (fett)
* Greedy: so viel wie möglich <.*> <a>Text</a><b>Tag</b> → ganzer String!
*? Lazy: so wenig wie möglich <.*?> <a>Text</a><b>Tag</b> → <a>, </a>, <b>, </b>
+ Greedy: 1 oder mehr \d+ "12345" → "12345" (alles)
+? Lazy: 1 oder mehr \d+? "12345" → "1" (erstes)
? Greedy: 0 oder 1 colou?r color oder colour
?? Lazy: 0 oder 1 colou??r color (bevorzugt kurzer)
{n} Genau n mal \d{4} 2024 (genau 4 Ziffern)
{n,} Mindestens n mal \d{3,} 123, 1234, 12345, ...
{n,m} Greedy: n bis m mal \d{2,4} "12345" → "1234" (4, greedy)
{n,m}? Lazy: n bis m mal \d{2,4}? "12345" → "12" (2, lazy)
*+ Possessive: kein Backtracking (PCRE) \d*+\d Matcht NIE (\d*+ konsumiert alles)
++ Possessive: 1 oder mehr (PCRE) \w++\d Vermeidet catastrophic backtracking
Zeichenklassen im Detail 
# EINFACHE KLASSEN
[aeiou]          # Eines von: a, e, i, o, u (Vokal)
[0-9]            # Ziffer 0 bis 9 (= \d)
[a-z]            # Kleinbuchstabe
[A-Z]            # Großbuchstabe
[a-zA-Z]         # Jeder Buchstabe
[a-zA-Z0-9_]     # Wort-Zeichen (= \w)
[^aeiou]         # KEIN Vokal (^ am Anfang = Negation)
[^0-9]           # Keine Ziffer (= \D)

# RANGES kombinieren
[a-fA-F0-9]      # Hexadezimale Zeichen
[a-z0-9_-]       # Slug-Zeichen (- am Ende! sonst Range)

# SONDERZEICHEN IN KLASSEN (meist literal!)
[ ]              # Leerzeichen
[.]              # Punkt (literal! kein Wildcard in [])
[*+?]            # * + ? literal
[(]              # Öffnende Klammer
[\[]           # Eckige Klammer (escaped)
[-]              # Minus (am Anfang oder Ende = literal)
[^]              # ^ (nicht am Anfang = literal)
[\^]             # ^ (mit Escape = immer literal)

# POSIX-KLASSEN (in ERE/einigen PCRE-Modi)
[:alpha:]        # [a-zA-Z]  – in [[ ]] verwenden: [[:alpha:]]
[:digit:]        # [0-9]
[:alnum:]        # [a-zA-Z0-9]
[:space:]        # Whitespace
[:upper:]        # Großbuchstaben
[:lower:]        # Kleinbuchstaben
[:punct:]        # Interpunktionszeichen
[:print:]        # Druckbare Zeichen

# UNICODE-KATEGORIEN (PCRE / Python / .NET)
\p{L}            # Jeder Unicode-Buchstabe (Letter)
\p{N}            # Jede Unicode-Ziffer (Number)
\p{Z}            # Jeder Unicode-Whitespace (Separator)
\p{P}            # Jedes Unicode-Satzzeichen (Punctuation)
\p{Lu}           # Uppercase Letter
\p{Ll}           # Lowercase Letter
\p{Nd}           # Decimal Number
\p{Latin}        # Lateinisches Script
\p{Greek}        # Griechisches Script
\P{L}            # KEIN Buchstabe (negiert mit \P)

# INTERSECTION & SUBTRACTION (Java/.NET/Ruby)
[a-z&&[^aeiou]] # Kleinbuchstaben OHNE Vokale (Java)
[a-z--[aeiou]]  # Kleinbuchstaben MINUS Vokale (Ruby)
Python – re Modul 
import re

text = "Kontakt: alice@example.com, bob@test.org"
email_rx = r"[\w.+-]+@[\w-]+\.[a-z]{2,}"

# SUCHEN
m = re.search(email_rx, text)      # Erstes Match
if m:
    print(m.group())               # alice@example.com
    print(m.start(), m.end())      # Position

# ALLE MATCHES
alle = re.findall(email_rx, text)  # Liste: ["alice@...", "bob@..."]
for m in re.finditer(email_rx, text):  # Iterator mit Match-Objekten
    print(m.group(), m.span())

# ERSETZEN
neu = re.sub(email_rx, "[VERSTECKT]", text)

# MIT FUNKTION
neu2 = re.sub(email_rx,
              lambda m: m.group().upper(), text)

# AUFTEILEN
teile = re.split(r"\s*,\s*", "a , b , c")  # ["a","b","c"]

# KOMPILIEREN (für Wiederverwendung!)
email_pattern = re.compile(email_rx, re.IGNORECASE)
m = email_pattern.search(text)

# FLAGS
re.IGNORECASE  # re.I
re.MULTILINE   # re.M  – ^ und $ für jede Zeile
re.DOTALL      # re.S  – . matcht auch 

re.VERBOSE     # re.X  – Kommentare erlaubt
re.UNICODE     # re.U  – Standard in Python 3

# NAMED GROUPS
datum_rx = r"(?P<jahr>\d{4})-(?P<monat>\d{2})-(?P<tag>\d{2})"
m = re.search(datum_rx, "Heute: 2024-01-15")
if m:
    print(m.group("jahr"))   # "2024"
    print(m.groupdict())     # {"jahr":"2024","monat":"01","tag":"15"}

# VERBOSE MODE (mit Kommentaren!)
email_verbose = re.compile(r"""
    [\w.+-]+        # lokaler Teil
    @               # @-Zeichen
    [\w-]+          # Domain
    \.              # Punkt
    [a-z]{2,}       # TLD
""", re.VERBOSE | re.IGNORECASE)

# ── GREP ──────────────────────────────────────────────────────────
grep "muster" datei.txt          # BRE (Basic Regex)
grep -E "muster+" datei.txt      # ERE (Extended Regex)
grep -P "\d{4}" datei.txt        # PCRE

grep -i "hallo" datei.txt        # Case-insensitive
grep -v "fehler" log.txt         # Invertiert (zeige NICHT-Treffer)
grep -n "TODO" code.py           # Mit Zeilennummern
grep -r "import" src/            # Rekursiv
grep -l "class" *.py             # Nur Dateinamen
grep -c "Error" log.txt          # Anzahl Treffer
grep -o "\d+" datei.txt          # Nur gematchten Teil

# Umgebung anzeigen
grep -A 3 "Fehler" log.txt       # 3 Zeilen NACH Treffer
grep -B 2 "Fehler" log.txt       # 2 Zeilen VOR Treffer
grep -C 2 "Fehler" log.txt       # 2 Zeilen beidseitig

# Mehrere Pattern
grep -e "Fehler" -e "Error" log.txt
grep -f muster.txt datei.txt     # Pattern aus Datei

# ── SED ───────────────────────────────────────────────────────────
# s/pattern/ersatz/flags
sed 's/alt/neu/' datei.txt       # Erster Treffer pro Zeile
sed 's/alt/neu/g' datei.txt      # Alle Treffer (global)
sed 's/alt/neu/gi' datei.txt     # Case-insensitive (GNU sed)
sed -i 's/alt/neu/g' datei.txt   # In-place ändern
sed -i.bak 's/alt/neu/g' d.txt   # In-place mit Backup

# Gruppen in sed (ERE mit -E)
sed -E 's/(\d{4})-(\d{2})-(\d{2})/../g' d.txt
# 2024-01-15 → 15.01.2024

# Zeilen löschen die Pattern matchen
sed '/^#/d' datei.txt            # Kommentarzeilen löschen
sed '/^$/d' datei.txt            # Leerzeilen löschen

# ── AWK ───────────────────────────────────────────────────────────
awk '/Fehler/ {print}' log.txt           # Zeilen mit "Fehler"
awk '/^\d{4}/ {print $1}' datei.txt     # Zeilen die mit Ziffer beginnen
awk '$0 ~ /Error/ {print NR": "$0}'     # Mit Zeilennummer

# Felder extrahieren
awk '/^\w+@/ {print $1}' emails.txt     # E-Mail-Adressen

using System.Text.RegularExpressions;

var text = "E-Mail: alice@example.com";

var compiled = new Regex(@"\d+",
    RegexOptions.Compiled);

var safe = new Regex(@"\d+",
    RegexOptions.None,

import re
from typing import Optional

# ── E-MAIL ────────────────────────────────────────────────────────
EMAIL_RX = re.compile(
    r"""
    ^                   # Anfang
    (?!.*\.\.)          # Kein .. im lokalen Teil
    [\w.!#$%&'*+/=?^_`{|}~-]+   # Lokaler Teil
    @                   # @-Zeichen
    (?:[a-z0-9]         # Domain: erstes Zeichen
    (?:[a-z0-9-]{0,61}[a-z0-9])?  # Domain: rest
    \.)+                # Punkt (min. ein)
    [a-z0-9][a-z0-9-]{0,61}[a-z0-9]  # TLD
    $                   # Ende
    """,
    re.VERBOSE | re.IGNORECASE
)

def ist_email(s: str) -> bool:
    return bool(EMAIL_RX.match(s))

# ── DEUTSCHE PLZ ────────────────────────────────────────────────
PLZ_RX = re.compile(r'^\d{5}$')

def ist_plz(s: str) -> bool:
    return bool(PLZ_RX.match(s))

# ── TELEFON (international, flexibel) ─────────────────────────
TELEFON_RX = re.compile(
    r'^'
    r'(?:\+|00)?'          # Optionale Ländervorwahl + oder 00
    r'[\d\s\-\(\)]{7,20}'  # Ziffern, Leerzeichen, -, (), 7-20 Zeichen
    r'$'
)

def ist_telefon(s: str) -> bool:
    # Erst normalisieren
    bereinigt = re.sub(r'\s+', ' ', s.strip())
    return bool(TELEFON_RX.match(bereinigt))

# ── PASSWORT-STÄRKE ──────────────────────────────────────────
def passwort_analyse(pw: str) -> dict:
    return {
        "länge_ok":      len(pw) >= 8,
        "hat_klein":     bool(re.search(r'[a-z]', pw)),
        "hat_gross":     bool(re.search(r'[A-Z]', pw)),
        "hat_ziffer":    bool(re.search(r'\d', pw)),
        "hat_sonder":    bool(re.search(r'[!@#$%^&*(),.?":{}|<>]', pw)),
        "kein_leerzeichen": not bool(re.search(r'\s', pw)),
    }

def ist_starkes_passwort(pw: str) -> bool:
    analyse = passwort_analyse(pw)
    return all(analyse.values())

# ── URL PARSEN ────────────────────────────────────────────────
URL_RX = re.compile(
    r'^(?P<schema>https?)://'
    r'(?P<host>[^/:?#]+)'
    r'(?::(?P<port>\d+))?'
    r'(?P<pfad>/[^?#]*)?'
    r'(?:\?(?P<query>[^#]*))?'
    r'(?:#(?P<fragment>.*))?$'
)

def parse_url(url: str) -> Optional[dict]:
    m = URL_RX.match(url)
    if not m:
        return None
    return {k: v for k, v in m.groupdict().items() if v is not None}

# ── DATUM EXTRAHIEREN ────────────────────────────────────────
DATUM_RX = re.compile(
    r'(?P<tag>0[1-9]|[12]\d|3[01])'
    r'[.\-/]'
    r'(?P<monat>0[1-9]|1[0-2])'
    r'[.\-/]'
    r'(?P<jahr>\d{4})'
)

def extrahiere_datum(text: str) -> list[dict]:
    return [m.groupdict() for m in DATUM_RX.finditer(text)]

print(extrahiere_datum("Am 15.01.2024 und 31-12-2023"))

# ── MARKDOWN ZU HTML ──────────────────────────────────────────────
def markdown_zu_html(text: str) -> str:
    # Überschriften
    text = re.sub(r'^#{6}\s+(.+)$', r'<h6></h6>', text, flags=re.M)
    text = re.sub(r'^#{5}\s+(.+)$', r'<h5></h5>', text, flags=re.M)
    text = re.sub(r'^#{4}\s+(.+)$', r'<h4></h4>', text, flags=re.M)
    text = re.sub(r'^#{3}\s+(.+)$', r'<h3></h3>', text, flags=re.M)
    text = re.sub(r'^#{2}\s+(.+)$', r'<h2></h2>', text, flags=re.M)
    text = re.sub(r'^#{1}\s+(.+)$', r'<h1></h1>', text, flags=re.M)

    # Fett und Kursiv
    text = re.sub(r'\*\*\*(.+?)\*\*\*', r'<strong><em></em></strong>', text)
    text = re.sub(r'\*\*(.+?)\*\*',     r'<strong></strong>', text)
    text = re.sub(r'\*(.+?)\*',          r'<em></em>', text)
    text = re.sub(r'__(.+?)__',          r'<strong></strong>', text)
    text = re.sub(r'_(.+?)_',            r'<em></em>', text)

    # Code (inline)
    text = re.sub(r'`(.+?)`', r'<code></code>', text)

    # Links
    text = re.sub(r'\[([^\]]+)\]\(([^)]+)\)', r'<a href=""></a>', text)

    # Bilder
    text = re.sub(r'!\[([^\]]*)\]\(([^)]+)\)', r'<img alt="" src="">', text)

    # Horizontale Linie
    text = re.sub(r'^---+$', '<hr>', text, flags=re.M)

    # Zeilenumbrüche
    text = re.sub(r'

', '</p>
<p>', text)

    return f'<p>{text}</p>'

# ── LOG-DATEI PARSEN ──────────────────────────────────────────────
LOG_RX = re.compile(
    r'(?P<timestamp>\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})'
    r'\s+\[(?P<level>DEBUG|INFO|WARN|ERROR|FATAL)\]'
    r'\s+(?P<logger>[\w.]+):'
    r'\s+(?P<nachricht>.+)'
)

def parse_logs(log_text: str) -> list[dict]:
    einträge = []
    for m in LOG_RX.finditer(log_text):
        einträge.append(m.groupdict())
    return einträge

log = """
2024-01-15 14:30:01 [INFO] app.main: Server gestartet
2024-01-15 14:30:05 [ERROR] db.pool: Verbindung fehlgeschlagen

"""

für_level = {}

    level = eintrag['level']
    für_level.setdefault(level, []).append(eintrag)

# ── CAMELCASE ↔ SNAKE_CASE ────────────────────────────────────────
def camel_zu_snake(name: str) -> str:
    # HTTPResponseCode → http_response_code
    s1 = re.sub(r'([A-Z]+)([A-Z][a-z])', r'_', name)
    s2 = re.sub(r'([a-z\d])([A-Z])', r'_', s1)
    return s2.lower()

def snake_zu_camel(name: str) -> str:
    return re.sub(r'_([a-z])', lambda m: m.group(1).upper(), name)

print(camel_zu_snake("HTTPResponseCode"))  # http_response_code
print(camel_zu_snake("myVariableName"))     # my_variable_name
print(snake_zu_camel("my_variable_name"))   # myVariableName

    if len(email) > 254:
        return False
    if email.count("@") != 1:
        return False
    lokal, domain = email.split("@")
    if not lokal or not domain:
        return False
    if "." not in domain:
        return False
    # Für Produktion: email-validator Bibliothek nutzen!
