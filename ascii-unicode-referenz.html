ASCII – American Standard Code for Information Interchange (1963). 7-Bit-Zeichensatz: 128 Zeichen (0–127). Basis von Unicode (die ersten 128 Codepoints sind identisch).
Tipp: Hex + 30 = ASCII-Ziffer ('0'=0x30) · Hex + 40 = Großbuchstabe ('A'=0x41) · Hex + 60 = Kleinbuchstabe ('a'=0x61)

Unicode – Universal Character Set. Version 15.1: über 149.000 Zeichen. UTF-8 ist die häufigste Kodierung: 1–4 Bytes pro Zeichen. ASCII (0–127) ist 1:1 in Unicode enthalten.
